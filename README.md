# news-image-20261126 — The World in One Day: 26 November 2026

One image summing up the world news of Thursday 26 November 2026, as a
front page with six panels:

1. **Houthis hit Saudi refinery** — strikes claimed on Ras Tanura; Brent crude above $94.
2. **US tariffs** — new tariffs announced, up to 15% on Taiwan, with plans for Japan, China and the EU.
3. **Pakistan's first astronaut** — joins China's Shenzhou-24 mission to the Tiangong station.
4. **Drone strikes kill 7 in Ukraine** — Russian strikes kill 7; Kyiv hits Russian refineries and an airfield.
5. **Poland plans no-fly zone** — on the Ukraine border.
6. **US confidence near 2-year high** — consumer confidence rises; the Fed's Beige Book reports modest growth.

## How it works

`main.py` (Python 3.13, standard library only, no network) copies the
pre-rendered `entry.png` (1024×1024, under 1 MiB) to
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`). The copy is
byte-for-byte, so both runs produce identical output.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
